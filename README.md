A bench vise modeled in Autodesk Fusion 360: 7 parts built from
technical drawings, then assembled into a full model.

## What I did
- Modeled each part using parametric modeling and sketch constraints
- Worked from technical drawings to get dimensions and specifications
- Assembled the parts into a full vise by constraining the components
